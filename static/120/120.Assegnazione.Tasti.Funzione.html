Come impostare il tasto funzione

Assegnando i seguenti tasti funzione ai tasti Preset, le funzioni possono essere utilizzate toccando i tasti assegnati.

OPERAZIONE DISPLAY (PT, kg, $/kg, $) NOTE
[MODE][MODE] [MODE] S1 → PLU FILE Entra in modalità S. Spia S accesa.
[4] o [≥] tre volte S4 → KEY ASSIGNMENT La modalità Assegnazione Tasti è il MENU 4 in modalità S.
[*] S4.0 PS AS 0 NO SET Entra in modalità assegnazione PLU.
[*] S4.1 VR AS 0 NO SET Entra in stato assegnazione Tasto Venditore.
[*] S4.2 FN AS 0 CLEAR Entra in stato assegnazione Tasto Funzione.
[X][X] S4.0 FN AS 2-PRICE Seleziona la funzione SCONTO PREZZO.
[PRESET 25] S4.2 FN AS 0 CLEAR La funzione SCONTO PREZZO è stata assegnata al Tasto Preset numero 25.
[×][C] S4 → KEY ASSIGNMENT Torna in modalità S.
Nota1: Un tasto Preset non assegnato può essere impostato come tasto funzione.
