1.4 Caratteristiche

  • Bilancia a stampa digitale composta da funzioni di registratore di cassa elettronico e funzione di stampa etichette.
  • Stampante a testina termica ad alta velocità e affidabilità, larghezza massima di stampa 60mm, velocità massima di stampa 110mm/sec.
  • Facilità di gestione della carta grazie al meccanismo appositamente progettato.
  • Taglierina Automatica (SM-120LL).
  • Orologio integrato che aggiorna automaticamente data e ora.
  • Risposta rapida alle variazioni di peso.
  • Capacità: 3kg, 6kg, 12kg, 15kg, 30kg, 6lb, 12lb, 15lb e 30lb.
  • Risoluzione: Risoluzione Display 1/3.000. : Risoluzione Interna 1/90.000.
  • Display cliente e operatore (display a colonna cliente opzionale).
  • LCD FSTN 202 x 32 pixel con retroilluminazione.
  • 55 (Banco) / 73 (Colonna / Elevato) tasti switch: Tasto ON/OFF, 10 tasti numerici, 32/56/72/120 tasti preset, 12/16 tasti operativi.
  • 18 file dati per Reparto, Gruppo Principale, PLU, ecc.
  • Vari report.
  • Funzione Ethernet.
  • Scheda Ethernet wireless opzionale.
  • Interfaccia RS232C per comunicazione dati e connessione scanner di codici a barre.
  • Cassetto contanti opzionale.

1.5 Specifiche

1.5.1 Display

  • Visualizzazione Peso Tara : 4 cifre.
  • Visualizzazione Peso : 5 cifre.
  • Visualizzazione Prezzo Unitario : 6 cifre.
  • Visualizzazione Prezzo Totale : 7 cifre.
  • Display Seconda Linea: 25 caratteri.

1.5.2 Condizioni operative

  • Fonte di Alimentazione : AC 100V ~ 240V, 50~60Hz.
  • Temperatura Operativa : - 10 °C ~ +40 °C.
  • Umidità Operativa : 15% ~ 85% RH.
  • Consumo Energetico : 0.5A.

1.5.3 Dimensioni

Dimensione piatto :356(L) x 283(P) mm.

Dimensioni complessive:

  • a) Banco : 361(L) x 427(P) x 146(A) mm.
  • b) Colonna : 361(L) x 500(P) x 584(A) mm.
  • c) Elevato : 361(L) x 470(P) x 531(A) mm.
  • d) BS EV 75tasti: 361(L) x 374 (P) x 725 (A) mm.
  • e) BS EV 120tasti: 361/500(L) x 374 (P) x 725 (A) mm.

TASTO ON/OFFAccende o spegne il display.

TASTO CHANGECalcola l'Importo del Resto. Esce dalla schermata di programmazione senza salvare i dati in modalità S.
TASTO MULTIPLE (X)Registra il numero di prodotti Non a Peso. Seleziona l'elemento di programmazione come dati PLU, Nome Negozio in modalità S. Seleziona Tipo Report in modalità X. Seleziona Tipo Transazione Dati in modalità Z.
TASTO CLERK (V1~V4)Accumula il Prezzo Totale.
TASTO VOIDCorregge i dati di vendita.
TASTO PLURichiama i dati PLU in modalità R. Memorizza i dati programmati in modalità S.
TASTO FEEDAvanza Etichetta o carta Scontrino.
TASTO PRINTStampa Etichetta o Scontrino.
TASTO SELEZIONE MODALITÀCinque Modalità possono essere selezionate usando questo tasto.
Indicatore R - MODALITÀ REGISTRAZIONE
Indicatore X - MODALITÀ VERIFICA
Indicatore S - MODALITÀ PROGRAMMAZIONE
Indicatore Z - MODALITÀ TOTALE
Indicatore X (Lampeggiante) - Modalità Impostazione Password
Tasto Diminuisci/Aumenta Conteggio SpecificheUsato solo quando si impostano SPEC 141 & 142. Seleziona dati parametro come dati SPEC. Sposta cursore a sinistra o destra.

3.2 Spiegazione Generale

I file REPARTO, GRUPPO PRINCIPALE e PLU sono collegati come mostrato di seguito. Con il seguente metodo di collegamento, è possibile ottenere informazioni più dettagliate e concrete sulla transazione di vendita o sui dati di pre-pack stampando vari report.

FILE REPARTO

Il FILE REPARTO è la categoria più ampia i cui articoli sono come CARNE, PESCE, VERDURA o GASTRONOMIA ecc.

FILE GRUPPO PRINCIPALE

Il file GRUPPO PRINCIPALE è la categoria intermedia che include articoli come MANZO, MAIALE, POLLO, ecc. È possibile collegare un Gruppo Principale a un Reparto nel file Gruppo Principale. Il Numero Tassa può essere assegnato a un Gruppo Principale. La Tassa assegnata si applicherà a tutti i PLU assegnati al Gruppo Principale.

FILE PLU

Il File PLU è la categoria più piccola che include articoli come FETTA DI MANZO, SPALLA DI MANZO e LOMBATA DI MANZO. È possibile collegare il PLU a un Gruppo Principale nel file di programmazione PLU.

[Diagramma ad albero: NEGOZIO -> REPARTO -> GRUPPO PRINCIPALE -> PLU]

3.3 File Reparto

Il file Reparto è usato per categorizzare i Gruppi Principali. I Numeri di Reparto tra 1 ~ 999999 sono disponibili per la programmazione. I Gruppi Principali che non sono collegati a nessun Reparto saranno assegnati automaticamente al Numero di Reparto 97. Sono disponibili massimo 16 caratteri per file e ognuno con 1 linea.

3.16 File Formato Libero

Il Formato Libero consente di progettare il proprio formato etichetta, impostando angoli di stampa, posizioni, dimensioni carattere e altri elementi programmabili. È possibile creare un nuovo formato copiandone uno esistente o creandone uno totalmente nuovo.

3.16.1 Informazioni Generali

  • È possibile creare formati entro le seguenti altezze e larghezze: Lunghezza 28mm ~ 220mm, Larghezza 30mm ~ 60mm.
  • Fino a 99 Formati Liberi possono essere memorizzati, oltre ai 16 formati standard.
  • I formati standard possono essere usati come base.
  • La posizione di stampa di ogni elemento è programmata in "mm".
  • Un'etichetta Articolo o un'etichetta Totale sono disponibili per ogni numero di Formato Libero (F1-F99).
  • 4 Angoli di Stampa possono essere impostati: 0, 90, 180 e 270 gradi.

3.16.2 Area di Stampa, Posizione di Stampa e Angoli di Stampa

La posizione di stampa di ogni elemento è determinata impostando l'intervallo dal punto "0" (X=0, Y=0) alla posizione base dell'elemento programmato. I valori X e Y devono essere inseriti in "mm".

Area di Stampa: I dati non devono essere stampati entro 1mm dal bordo dell'etichetta.

Posizione di Stampa: Decisa dalla distanza dal punto 0 (X=0, Y=0) alla posizione base (X, Y).

Angolo di Stampa: Selezionabile tra 0, 90, 180 e 270 gradi. Può essere impostato per l'intero formato o per singoli elementi. A seconda dell'angolo, la posizione di stampa cambia.

Il tasto [CODE] commuta tra l'inserimento carattere e l'inserimento codice.

Esempio: Per inserire "CAKE", premere [CODE], poi [6][7] per 'C', [6][5] per 'A', ecc.

4. MODALITÀ REGISTRAZIONE

4.1 ON/OFF

Accensione e spegnimento tramite il tasto [ON/OFF].

4.2 Reset e Verifica Peso

Tutte le operazioni di pesatura si basano sulla procedura mostrata. L'operatore dovrebbe verificare prima di qualsiasi transazione (posizionare peso, controllare lettura, rimuovere peso, azzerare con [REZERO]).

4.3 Sottrazione Tara

4.3.1 Sottrazione Tara One touch

Mettere la tara sul piatto e premere [T]. Premere di nuovo [T] per rimuoverla.

4.3.2 Sottrazione Tara Digitale

Inserire il valore della tara con i tasti numerici e premere [T].

4.4 Chiamata PLU

Ci sono tre modi per richiamare un PLU programmato:

  • Chiamata PLU Manuale (inserire numero e premere [PLU]).
  • Tramite tasto preset assegnato.
  • Chiamata PLU Automatica (a seconda delle SPEC 39 e 40).

4.5 Operazione Fix

Permette di fissare Tara, PLU o Prezzo Unitario premendo il tasto [FIX].

4.6 Cambio Modalità Operativa

Tenere premuto [REZERO] e premere [MODE] per passare da modalità Scontrino a Etichetta e viceversa.

4.7 Stampa Etichetta Articolo in Modalità Manuale

4.7.1 Stampa Etichetta per Articolo PLU

Esempio: Vendere 1kg di BEEF STEAK (PLU #10). Inserire [1][0], premere [PLU], mettere il prodotto, premere [*] per stampare.

4.7.2 Stampa Etichetta per Articolo NON-PLU

Inserire il prezzo con i tasti numerici, premere [*] per stampare (o [X] per la quantità). Gli articoli non-PLU vengono registrati su PLU #999998 (a peso) o #999999 (non a peso).

4.8 Stampa Etichetta Totale in Modalità Manuale

4.8.1 Transazione di Vendita

Esempio: Vendere 1.5kg di HERB CHEESE e 2 pacchi di SKIM MILK per il cliente A. Utilizzare i tasti [V1] per accumulare e [*] per stampare il totale.

4.8.2 Tasto [SCONTO PREZZO] in Modalità Add

Sottrae un valore di sconto dal totale. (Il tasto deve essere assegnato in precedenza).

4.8.3 Tasto [SCONTO PREZZO %] in Modalità Add

Applica uno sconto percentuale al totale. (Il tasto deve essere assegnato in precedenza).

4.9 Correzione Dati

Corregge i dati di vendita prima dell'emissione dello scontrino/totale.

4.9.1 Correzione Sul Posto

Annulla l'ultimo articolo inserito premendo [-] e [C].

4.9.2 Correzione tramite Annullamento Articolo

Annulla una transazione specifica tracciandone il numero.

4.10 Stampa Etichetta Articolo in Modalità Pre-pack

La modalità Pre-pack si attiva con il tasto [AUTO]. L'etichetta viene emessa automaticamente al raggiungimento della stabilità del peso (articoli a peso) o alla rimozione dell'etichetta precedente (non a peso).

5. MODALITÀ REPORT DI LETTURA

5.1 Selezione Fattore Report

Premere [MODE] due volte per entrare in modalità X. Usare i tasti [X] o [^]/[v] per scorrere i tipi di report.

5.2 Selezione Tipo Report

I report includono: Gruppo Principale, PLU, Reparto, Vendite, 24 Ore, ABC, Commesso, Pre-pack, Tasse, Riassuntivo Negozio, Tracciabilità, Log Commesso, Batch, e Programmabile dall'Utente.

Per ogni report, viene richiesto di inserire un limite inferiore e superiore (es. da PLU 3 a PLU 999996) e premere [*] per stampare.

6. MODALITÀ REPORT DI RESET

6.1 Report di Reset

Entrare in modalità Z (premere [MODE] tre volte). Selezionare il tipo di reset (Giornaliero, Mensile, a Termine, Tracciabilità, Log Commesso). Premere [*] e confermare con [C] per cancellare i dati.

9. Aggiornamento Firmware

9.1 Firmware

Esempio pacchetto: STE58package_STD_v0101_ftp(SM120+).zip (include file .bap, .txb, .bin, .hey). Utility: MiniProgrammer V5.0.

9.2 Procedura

  1. Impostare l'IP del PC su 10.10.10.1 - 10.10.10.200.
  2. Avviare MiniProgrammer V5.0, selezionare SM-120.
  3. Aprire il file firmware da caricare.
  4. Collegare la bilancia al PC.
  5. Spegnere la bilancia, tenere premuto [Rezero] e [Preset 22] e riaccendere.
  6. Il display mostra "S-OFF". Se SPEC657=0, premere [Rezero] e "3752"; se SPEC657=1, premere lo Span Switch per 3 secondi.
  7. Selezionare "1-ETHERNET" sul display della bilancia.
  8. Il display mostra "SCALE READY UPDATE".
  9. Sul PC, cliccare "Run" per avviare l'aggiornamento.
  10. Attendere il completamento del trasferimento.
  11. Ripetere per gli altri file (const, bmap, hey). Attenzione: aggiornare il file .hey per ultimo per evitare problemi di "Loss of main software".

9.3 Carica SPEC Predefinite

Dopo l'aggiornamento, accendere la bilancia, entrare in modalità Z, accendere lo Span Switch, premere [Rezero] e "8822". Selezionare il codice paese (es. 2 per STD), premere [Print]. Premere [Y] per caricare le SPEC predefinite, [C] per cancellare la memoria, quindi riavviare.

13. Funzionalità Comuni

13.1 Funzione Server/Client

Tre funzioni principali: Commesso flottante (SPEC61), Sincronizzazione file dati (SPEC491), Chiamata PLU dal server (SPEC492). Massimo 5 bilance (1 Server, 4 Client).

Impostazioni: SPEC50 (0 Client, 1 Server), SPEC61 (0 Inibisci, 1 Consenti), SPEC150, SPEC194 (IP Server), SPEC254, SPEC491, SPEC492, SPEC520, SPEC539 (Codice Nodo Macchina).

13.2 Impostazione Tracciabilità

Impostare SPEC258 su "1". Programmare i file Paese, Sala di Taglio, Macello, Tipo, Categoria, Razza, e infine il file Tracciabilità (S37) collegando tutti i dati. Abilitare la stampa nel Formato Libero e nel PLU.

13.3 Impostazione Etichetta Nutrizionale

Usa 12 template fissi (No. 70~81). Impostare in S19 "IMAGE" e "NUTRI" su PROGRAM. Impostare l'area di stampa in S12 (IMG 1~10). Nel PLU (S1), selezionare il template e abilitare la stampa.

13.4 Stampa Allergeni

Metodo 1: Usare il file allergeni (S25) e impostare SPEC534 (0 No, 4 Frame, 5 Inverse, 6 Underline) e SPEC535. Metodo 2: Usare tag HTML nel file ingredienti (S10) impostando SPEC534=7 (es. `peanut` per frame).

13.5 Report Programmabile dall'Utente

Abilitare con SPEC524=1. Creare le linee del report in S22, collegare i dati in S23, definire la sequenza in S24. Stampare da X0.4 o assegnando un tasto preset in S4.3.

13.6 Codice a Barre 2D

Supporta PDF417, GS1 QR Code, GS1 DataMatrix, GS1 DataBar Composite. Impostare SPEC310 (tipo), SPEC530 (stampa su scontrino/totale), SPEC531 (HRI).

13.7 Testo Codice a Barre 2D

Programmare il testo in S32, creare un Multi-barcode in S31 (tipo T2D), e collegarlo al PLU in S1.72. Usare simboli come `%%(1208)` per inserire dati dinamici (es. nome merce).

13.8 Collegamento SM-120LL con @Label

Configurare la bilancia come Server (SPEC50=1) e impostare l'IP del PC. Su @Label (web), creare la bilancia, i formati di stampa, i codici a barre flessibili, i multi-barcode e i PLU. Inviare i dati alla bilancia.

13.9 Etichetta Prezzo Sconto SM-120

Richiede il file bmap specifico. Usa 4 tipi di tag. Programmare in S12 (Formato Libero, selezionare 88), impostare X, Y, larghezza (60mm), altezza (16mm), stato e tipo tag (0-3). Nel PLU, impostare il tipo di sconto (S1.29) e markdown (S1.34).

13.10 Stampa Codice a Barre 2D tramite @Label

Procedura guidata su @Label per creare un formato con multi-barcode 2 (GS1 QR), impostare il PLU con barcode ITF e multi-barcode 2, inviare alla bilancia e stampare.

13.12 Stampa Immagine tramite @Label

Simile alla precedente, ma si importa un'immagine (es. .bmp) in @Label, si crea un formato con l'immagine, si imposta il PLU e si invia.

13.13 SM-120 Auto-Sizing

Permette di tagliare etichette continue in altezze diverse a seconda del contenuto (es. con o senza ingredienti). Impostare SPEC181=1 o 2. Programmare i formati (S12) e i testi (S11) per le diverse sezioni, quindi impostare i PLU per usare il formato e i messaggi.

13.14 Impostazione Scanner

Configurare lo scanner (baud rate 9600, 8 bit, no parity, 1 stop bit) e la bilancia (SPEC51-54, SPEC60=4 per scansione). Assegnare il tasto funzione per l'inserimento manuale del barcode (S4.2 FN AS 91).
