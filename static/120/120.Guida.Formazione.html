1.4 Esempi di Report

Il manuale originale mostra numerosi esempi di report stampati. Di seguito la lista dei report disponibili e una loro descrizione:

  • X1.1 READ MG DAILY: Report giornaliero Gruppo Principale (M.G. #, Support Rate, Customer, Actual Price, Planned Price, Quantity, Weight, Profit, Last Act Date, Discount Price, Price/Customer, Quantity/Customer, Price/Quantity).
  • X2.1 READ PLU DAILY: Report giornaliero PLU (PLU#, Nome, Actual Price, Planned Price, Quantity, Weight, Profit, Last Act Date).
  • X3.1 READ DEPT DAILY: Report giornaliero Reparto (DEPT.#, Support Rate, Customer, Actual Price, Planned Price, Quantity, Weight, Profit, Last Act Date, Discount Price, Refund Count, Refund Price).
  • X4.1 READ SALES DAILY: Report giornaliero Vendite (Grand Total, Gross Sale Quantity/Weight/Amount, Discount, PLU Percent Discount, PLU Amount Discount, Percent Discount, Amount Discount, Item Correct, Void, Refund, Net Sale, SP Rounding, Customer, Cash Sales, Credit Sales, Received-on-account, Paid Out, Cash-in-drawer, Receipt Consecutive Number).
  • X5.1 READ 24 HOUR DAILY: Report giornaliero 24 Ore (Store Total, fasce orarie 11H-12H, ecc. con Actual Price, Planned Price, Customer, Quantity, Price/Customer, Quantity/Customer, Price/Quantity).
  • X6.1 READ ABC DAILY: Report giornaliero ABC (Rank A, B, C con PLU#, Actual Price, percentuali).
  • X7.1 READ CLERK DAILY: Report giornaliero Commesso (Clerk #, Actual Price, Planned Price, Customer, Quantity, Weight, Price/Customer, ecc.).
  • X8.1 READ PPK DEPT DAILY: Report giornaliero Pre-pack Reparto (DEPT.#, Actual Price, Planned Price, Quantity, Weight, Profit, Weight/Quantity, Price/Quantity).
  • X3.2 READ DEPT MONTHLY: Report mensile Reparto.
  • X4.2 READ SALES MONTHLY: Report mensile Vendite.
  • X5.2 READ 24 HOUR MONTHLY: Report mensile 24 Ore.
  • X8.2 READ PPK MG DAILY: Report giornaliero Pre-pack Gruppo Principale.
  • 1.4 READ MG TERM: Report a termine Gruppo Principale.
  • 2.4 READ PLU TERM: Report a termine PLU.
  • 3.4 READ DEPT TERM: Report a termine Reparto.
  • X4.4 READ SALES TERM: Report a termine Vendite.
  • X5.4 READ 24 HOUR TERM: Report a termine 24 Ore.
  • X6.4 READ ABC TERM: Report a termine ABC.
  • X9.4 READ TAX: Report Tasse (TAX1 VAT, Amount Incl., Amount Excl., Tax Amount).
  • X4.3 READ STORE SUMMARY: Report riassuntivo del negozio (Manual Mode Summary, Prepack Mode Summary, Total Summary).
  • X0.1 TRACEABILITY REPORT: Report Tracciabilità (Reference#, PLU, Weight, Total).
  • X0.2 CLERK LOG REPORT: Report Log Commesso (Clerk#, Reported, PLU#, Old Unit Price, New Unit Price, Supervisor ID).
  • X0.3 BATCH REPORT: Report Batch (definito dall'utente).
  • X0.4 USER PROGRAM REPORT: Report programmabile dall'utente.
  • X0.5 UPLOAD FISCAL DATA: Caricamento dati fiscali (richiede SPEC723=1).
